# Week 10：项目总结与系统操作手册

## 本周目标

整合前九周的实验过程，形成从驱动、数据转换、Gmapping 建图到 AMCL 与 Move Base 导航的完整操作说明，并整理项目汇报材料和最终结果。

## 目录内容

- [项目操作手册（Markdown）](Week10_实操手册_李响.md)：完整系统说明与复现流程
- [项目操作手册（PDF）](Week10_实操手册_李响.pdf)：便于阅读和归档的导出版
- [项目汇报 PPT](Week10_项目汇报_李响.pptx)：阶段总结与结果展示
- [任务要求状态说明](task_requirement_status.md)：Week 10 任务材料的来源情况
- `images/`：地图、TF、RViz 与真实机器人导航结果

## 手册覆盖内容

1. 项目目标与软硬件环境。
2. 驱动、深度图转 LaserScan、Gmapping 建图的启动顺序。
3. 地图加载、AMCL 定位与 Move Base 导航流程。
4. 深度转激光、AMCL 与局部规划器的关键参数。
5. 系统正常运行时应达到的状态。
6. 实验过程中常见问题及解决思路。

源材料中未找到独立的 Week 10 任务要求 PDF，因此本目录不补造任务书；`task_requirement_status.md` 只说明当前材料状态。

## 复现建议

首次复现应先阅读 Markdown 手册，再回到 Week 5–9 查看对应实验报告。真实设备启动时，应按“驱动与 TF → 传感器数据 → 建图或地图服务 → 定位 → 导航”的顺序逐层验证，不要一次启动全部节点后再排错。
