# Week 9：真实移动机器人定位与自主导航

## 本周目标

加载已保存的地图，在真实移动机器人上运行 AMCL 与 Move Base，观察定位效果，完成自主导航闭环测试，并对定位或局部规划参数进行调整与对比。

- [任务要求](task_requirement.pdf)：课程任务原文件，仅用于说明实验背景

- `真实小车导航成功截图`：导航闭环结果

- `images/`：地图、定位、路径规划与导航截图

## 复现重点

1. 启动地图服务器并确认 `/map` 正常发布。
2. 启动传感器、里程计、AMCL 与 Move Base。
3. 在 RViz 中设置初始位姿并观察粒子收敛。
4. 设置导航目标，检查全局路径、局部路径和避障表现。
5. 每次只修改少量参数，记录修改前后的现象并保留备份。

导航结果受地图质量、传感器噪声、里程计、机器人尺寸和场地动态障碍影响。报告中的参数不应直接复制到不同设备；真实机器人测试必须预留安全距离并准备随时停止。
