# Week 8：真实移动机器人 Gmapping 建图

## 本周目标

从仿真过渡到真实移动机器人，启动底盘与深度相机驱动，将深度数据转换为二维 LaserScan，检查里程计与 TF，并运行 Gmapping 完成实时建图。

- [实验报告](team4_李响_week8_final.md)：真实设备启动、数据检查、建图与排错过程
- [任务要求](task_requirement.pdf)：课程任务原文件，仅用于说明实验背景
- `简要实验说明`：本周实验的简要记录
- `TF树`、`rviz`：TF 与可视化结果
- `images/`：真实设备、话题、地图和运行截图

## 复现重点

1. 确认移动机器人、深度相机和上位机网络连接。
2. 启动设备驱动并检查深度图、相机信息与里程计。
3. 生成 `/scan` 并检查数据类型、频率和有效范围。
4. 验证 `map`、`odom`、`base_link` 与传感器 frame 的 TF 链。
5. 启动 Gmapping，低速控制机器人完成地图覆盖并保存结果。

本周依赖特定真实硬件和厂商驱动。复现时必须使用与设备匹配的官方说明，并在运动前检查急停、周边空间和人员安全。截图中的设备与厂商标识仅用于记录实验环境。
