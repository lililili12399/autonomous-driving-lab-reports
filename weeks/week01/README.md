# Week 1：Ubuntu、开发工具与 Git 基础

## 本周目标

完成 Ubuntu 双系统安装与基础配置，安装 VS Code，练习 Git 基本操作，并使用 Markdown 编写第一份实验报告。本周为后续 ROS 实验准备统一的操作系统和开发工具环境。

## 目录内容

- [实验报告](team4_李响_week1_final.md)：完整操作过程、问题处理与总结
- [任务要求](task_requirement.pdf)：课程任务原文件，仅用于说明实验背景
- `images/`：系统安装、VS Code、Git 与 Markdown 操作截图

## 复现重点

1. 安装 Ubuntu 并完成时间、启动项和网络配置。
2. 安装 VS Code 及所需扩展。
3. 配置 Git，练习仓库克隆、提交和推送流程。
4. 使用 Markdown 组织实验步骤、图片和总结。

双系统安装涉及磁盘分区和启动项修改，复现前应备份重要文件，并根据自己的设备调整分区方案。报告中的仓库地址和路径仅代表当时的实验环境。
